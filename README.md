## Perfil profesional

<p align="center"><img src="./images/mahiro_switch.png" width="105" alt="Ilustración representando evolución y adaptación tecnológica" /></p>

Soy **Ingeniero Informático titulado en INACAP**, enfocado en crear software que resuelva problemas concretos. Mi trabajo combina **Python, Django, PostgreSQL, automatización, integración de APIs, inteligencia artificial aplicada y desarrollo de productos web y de escritorio**.

Me interesa especialmente transformar necesidades reales en sistemas mantenibles: desde plataformas operativas para negocios hasta asistentes inteligentes, automatizaciones, herramientas de productividad y experiencias conversacionales.

### Qué hago

| Área | Enfoque |
| --- | --- |
| **Backend & sistemas** | Lógica de negocio, APIs, autenticación, procesos operativos, Django y PostgreSQL. |
| **IA aplicada** | Asistentes, modelos locales, LLMs, prompting, RAG e integración con servicios de IA. |
| **Automatización** | Procesos programados, notificaciones, integraciones y herramientas internas. |
| **Productos digitales** | Aplicaciones web, escritorio y móvil con foco en usabilidad, estabilidad y evolución continua. |

## Proyectos destacados

<p align="center"><img src="./images/mahiro_flex.png" width="105" alt="Ilustración asociada a proyectos y logros" /></p>

### 🧺 FastLaundry

**Sistema de gestión real para una lavandería**, orientado a clientes, pedidos, caja, pagos, guías, reparto y operación diaria.

- **Stack:** Python 3.12 · Django 5.2 · PostgreSQL
- **Enfoque:** procesos reales de negocio, consistencia de datos, control operativo y evolución mantenible.
- **Estado:** proyecto privado de uso operativo.

### 🤖 Carey Assistant

**Aplicación de escritorio para Windows** orientada a asistencia personal, automatización y uso de IA local.

- **Stack:** Tauri · React · TypeScript · Rust · Ollama
- **Incluye:** chat con IA local, selección de modelos, noticias, caché local, automatizaciones y notificaciones.
- **Código principal:** privado.
- **Distribución pública:** [Carey Assistant Releases](https://github.com/SC-Sergio/carey-assistant-releases)

### 🌐 [Portfolio v2](https://github.com/SC-Sergio/sergio-portfolio-v2)

Portafolio profesional moderno con identidad visual tecnológica y experiencia 3D liviana.

- **Stack:** Next.js · TypeScript · Tailwind CSS · Motion · Three.js
- **Demo:** [sergio-portfolio-v2-roan.vercel.app](https://sergio-portfolio-v2-roan.vercel.app)

### 🏟️ [CanchaClara](https://github.com/SC-Sergio/canchaclara)

Plataforma para gestión y reserva de canchas deportivas.

- **Stack:** Vue · JavaScript · MySQL

### 🚀 [SpaceX Falcon 9 Landing Prediction](https://github.com/SC-Sergio/SpaceX_Falcon9_Landing_Prediction)

Proyecto de ciencia de datos centrado en análisis y predicción de aterrizajes del Falcon 9.

- **Formato principal:** Jupyter Notebook
- **Área:** análisis exploratorio, visualización y machine learning.

## Cómo trabajo

<p align="center"><img src="./images/mahiro_cry.png" width="100" alt="Ilustración representando debugging y mejora continua" /></p>

- Analizo el problema y el flujo real antes de implementar.
- Priorizo soluciones simples, mantenibles y verificables.
- Trabajo de forma incremental, con pruebas y revisión de regresiones.
- Cuido la integridad de datos y la separación entre desarrollo y producción.
- Documento decisiones importantes para facilitar mantenimiento y continuidad.
- Busco que la interfaz y la experiencia sean tan claras como la lógica interna.
